# NeonVisuals 1.21.11 (Fabric)

Client-only visual mod. Press Right Shift to open the settings screen.

## Combat
- Hit particles with Crit / Stars / Hearts / Enchanted presets
- Burst / Ring / Upward particle layouts
- Predicted critical-hit spark burst
- Hitmarker and combo counter
- Damage readout when the targeted entity's health updates
- Totem burst when the tracked target dies

## HUD
- Target HUD with target name, health bar and distance
- Armor icons and durability bars
- Potion effect names and timers
- WASD, jump, sneak and sprint key display
- Coordinates and FPS panel
- CPS counter
- Optional crosshair accent

## World
- Fullbright option using the maximum vanilla gamma setting (restores previous gamma when disabled)
- Extended render-distance fog (environmental fog remains vanilla)
- Player movement trail
- Jump rings
- Ambient particles

Settings are saved in config/neonvisuals.properties. Combat visuals are client-side feedback; the server remains authoritative for hits and damage.
